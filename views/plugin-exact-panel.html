🛡️ اقدامات و سپرهای امنیتی اختصاصی فرم‌های ورود و عضویت (Login Hardening)

فعال یا غیرفعال‌سازی دقیق تک‌تک استانداردهای ضد نفوذ، ضد بروت‌فورس (Brute-Force) و جلوگیری از اسکن نام کاربری مدیران:

🔒 پنهان‌سازی خطاهای تفکیکی وردپرس (Generic Login Error Messages)

🛑 مسدودسازی اسکن نام کاربری نویسندگان و مدیران (Anti Author Scan)

⚡ مسدودسازی هوشمند حملات بروت‌فورس و تلاش‌های مکرر (Brute-Force Rate Limiting)
مسدودسازی موقت IP پس از تعداد مشخص تلاش ناموفق برای ورود به حساب کاربری.
🚫 غیرفعال‌سازی پروتکل XML-RPC وردپرس
مسدودسازی نقطه اتصال xmlrpc.php که اغلب مورد سوء‌استفاده حملات DDoS و Brute-Force قرار می‌گیرد.
🔑 غیرفعال‌سازی رمز عبور برنامه‌ها (Application Passwords)
جلوگیری از ایجاد توکن‌های دسترسی برنامه توسط کاربران در صورت عدم نیاز.
🛡️ ارسال هدرهای امنیتی ضد کلیک‌جکینگ (Anti-Clickjacking Headers)
تزریق هدرهای X-Frame-Options: SAMEORIGIN و X-Content-Type-Options: nosniff در صفحه لاگین.
🔒 غیرفعال‌سازی ورود با ایمیل (اجبار به نام کاربری)
اجبار کاربران به وارد کردن تنها نام کاربری جهت جلوگیری از حدس زدن ایمیل‌های سازمانی.

تله مخفی هانی‌پات (Honeypot Trap)

ارسال‌های سریع‌تر از این زمان به عنوان اسکریپت رباتیک شناسایی و مسدود می‌شوند.

قفل ضد حمله Brute-Force و محدودسازی نرخ خطا (Rate Limiting)
مسدودسازی موقت آدرس‌های IP پس از خطاهای متوالی در حل کپچا به منظور جلوگیری از حملات ربات‌ها و آزمون‌وخطا.

افزودن خودکار آدرس IP مهاجم به لیست سیاه سراسری در صورت تکرار خطاهای متوالی و رسیدن به سقف تلاش‌های غیرمجاز.
پس از این تعداد تلاش اشتباه متوالی، آدرس IP کاربر به صورت خودکار مسدود می‌شود.

مدت زمان انقضای توکن برای جلوگیری از حملات معلق (پیش‌فرض: ۲ دقیقه).
پس از این مدت، چالش کپچا به صورت خودکار رفرش می‌شود تا امنیت افزایش یابد (پیش‌فرض: ۱۲۰ ثانیه).

۲. تله مخفی و نامرئی هانی‌پات (Honeypot)

تزریق فیلدهای تله نامرئی در کدهای فرم. ربات‌های خودکار هنگام اسکن فرم این فیلدها را به اشتباه پر می‌کنند؛ در نتیجه بدون کوچک‌ترین مزاحمت برای کاربران واقعی، ربات بلافاصله شناسایی و مسدود می‌شود.

⏱️

۳. آنالیز سرعت ارسال (Velocity Check)

محاسبه هوشمند اختلاف زمان میان لود فرم در مرورگر و کلیک روی دکمه ارسال. فرم‌هایی که زیر ۲ ثانیه (قابل تنظیم) سابمیت شوند به عنوان اسکریپت‌های حمله ماشینی مسدود خواهند شد.

👁️

۴. حفاظت امنیتی هوشمند و پایش رفتار انسانی (Smart Inspection)

استفاده از الگوریتم‌های تحلیل بیومتریک رفتار انسانی، بررسی سرعت طبیعی تکمیل فرم (Velocity Check)، حسگرهای تعاملی و نشانگر پایش راداری هوشمند بدون افت سرعت لود صفحه و بدون تحمیل فشار پردازشی بر سرور.

۵. محافظت ۳۶۰ درجه از فروشگاه ووکامرس

ادغام اختصاصی با ووکامرس (WooCommerce Integration API) - ثبت‌نام و تسویه حساب

با قرار دادن قطعه کد زیر در فایل functions.php قالب چایلد، تابع guardify_validate_captcha در هوک‌های حیاتی woocommerce_registration_errors و woocommerce_checkout_process فراخوانی شده و صفحه تسویه حساب در برابر تست کارت‌های بانکی سرقتی (Card Testing) و ثبت سفارشات فیک ربات‌ها کاملاً مسدود می‌گردد: 

<?php
/**
 * ادغام دستی گاردفای با فرم‌های پیش‌فرض فروشگاه‌ساز ووکامرس
 */

// ۱. تزریق ویجت کپچا به فرم ثبت‌نام ووکامرس
add_action('woocommerce_register_form', 'guardify_custom_woo_register_captcha');
function guardify_custom_woo_register_captcha() {
    if (function_exists('guardify_render_captcha')) {
        echo guardify_render_captcha();
    } elseif (class_exists('Guardify_Captcha_Engine')) {
        echo Guardify_Captcha_Engine::render_widget();
    }
}

// ۲. اعتبارسنجی در هوک woocommerce_registration_errors (فرم ثبت‌نام مشتریان)
add_filter('woocommerce_registration_errors', 'guardify_custom_woo_register_validation', 10, 3);
function guardify_custom_woo_register_validation($errors, $username, $email) {
    if (function_exists('guardify_validate_captcha')) {
        $validation = guardify_validate_captcha('ثبت‌نام مشتری ووکامرس');
        if (is_wp_error($validation)) {
            $errors->add('guardify_captcha_error', $validation->get_error_message());
        }
    }
    return $errors;
}

// ۳. تزریق ویجت کپچا به صفحه تسویه حساب (قبل از دکمه ثبت سفارش)
add_action('woocommerce_review_order_before_submit', 'guardify_custom_woo_checkout_captcha');
function guardify_custom_woo_checkout_captcha() {
    if (function_exists('guardify_render_captcha')) {
        echo '<div class="guardify-checkout-box" style="margin:15px 0;">' . guardify_render_captcha() . '</div>';
    } elseif (class_exists('Guardify_Captcha_Engine')) {
        echo '<div class="guardify-checkout-box" style="margin:15px 0;">' . Guardify_Captcha_Engine::render_widget() . '</div>';
    }
}

// ۴. اعتبارسنجی در هوک woocommerce_checkout_process (تسویه حساب)
// مسدودسازی تست کارت‌های بانکی سرقتی (Card Testing) و ثبت سفارشات فیک ربات‌ها
add_action('woocommerce_checkout_process', 'guardify_custom_woo_checkout_validation');
function guardify_custom_woo_checkout_validation() {
    if (function_exists('guardify_validate_captcha')) {
        $validation = guardify_validate_captcha('تسویه حساب ووکامرس (Checkout)');
        if (is_wp_error($validation)) {
            wc_add_notice($validation->get_error_message(), 'error');
        }
    }
}

اگر در حین تست متوجه شدید هر پاسخی را قبول می‌کند، به این دلیل است که به عنوان مدیر سایت (Administrator) لاگین هستید و گزینه «استثنا کردن مدیران و کاربران وارد شده» در تب امنیت روشن است. برای تست واقعی اعتبارسنجی و مشاهده خطای پاسخ اشتباه، فرم را در یک پنجره ناشناس مرورگر (Incognito / Private Window) یا در حالت خروج از حساب تست فرمایید.

🚀 راهنمای گام‌به‌گام کار با پنل مدیریت (شروع سریع)
۱. پایش و تحلیل (Monitoring)

پس از نصب، ابتدا به تب «آمار و گزارشات» بروید. در این بخش می‌توانید نمودار روند حملات را در بازه‌های ۷ روز تا ۱ سال فیلتر کنید. بخش‌های «آمار سیستم‌عامل‌ها» و «آمار مرورگرها» به شما کمک می‌کنند تا هویت، پلتفرم و کلاینت‌های ربات‌های مهاجم را با گزارش‌های آماری دقیق و درصدی بررسی کنید.

۲. پیکربندی و شخصی‌سازی (Configuration)

در تب «تنظیمات عمومی» متن‌ها و دشواری سوالات را تعیین کنید. سپس در تب «انتخاب تم»، یکی از پوسته‌های لوکس را انتخاب نمایید. تمامی تم‌ها دارای انیمیشن‌های شناور (Gravity) و پایش راداری هستند که ظاهر سایت شما را حرفه‌ای‌تر نشان می‌دهند.

۳. مدیریت امنیت و لیست سیاه (Security Operations)

در انتهای صفحه آمار، «آخرین رویدادهای امنیتی» را پایش کنید. اگر آی‌پی خاصی مشکوک بود، مستقیماً از همان‌جا آن را مسدود کنید. آی‌پی‌های مسدود شده در باکس «مدیریت لیست سیاه» قابل آزادسازی هستند.

❓ پرسش‌های متداول و راهنمای حل سریع مشکلات

چرا با تغییر رنگ تم، ظاهر در صفحات مختلف متفاوت بود؟ (بهینه‌سازی شده در v3.5)

در نسخه جدید، تمامی استایل‌ها به صورت ایزوله و با استفاده از متغیرهای CSS مستقیم تزریق می‌شوند. این یعنی تنظیمات شخصی‌سازی شما (رنگ، گردی کادر و...) بدون تداخل با استایل‌های قالب یا سایر افزونه‌ها، در تمامی ماژول‌ها از جمله المنتور، فرم تماس ۷ و ووکامرس به صورت یکپارچه اعمال می‌گردد.

آیا کپچا با افزونه‌های کش و بهینه‌سازی (WP Rocket, LiteSpeed Cache, Super Cache) سازگار است؟

بله، صد در صد. به دلیل اینکه توکن‌های امنیتی بر اساس رمزنگاری زمان‌بندی‌شده (HMAC با انقضای معتبر) تولید می‌شوند و موتور احیای خودکار جاوااسکریپت در صفحات کش‌شده فرم‌ها را با چالش تازه و معتبر همگام می‌کند، هیچ‌گونه خطای انقضای کپچا یا تداخل در محاسبات ریاضی در صفحات کش‌شده پیش نمی‌آید.

سامانه حفاظت امنیتی هوشمند (Smart Inspection) چگونه کار می‌کند؟

این سیستم به صورت هوشمند و بدون ایجاد مزاحمت یا صدا، رادار پویا، سرعت تکمیل فرم، تعاملات ماوس/لمس (Human Telemetry) و تله‌های پنهان هانی‌پات را بررسی می‌کند. اگر ارسال فرم توسط ربات خودکار در کسری از ثانیه صورت گیرد، حمله بلافاصله خنثی شده و با امتیاز ریسک در رادار لاگ‌ها ثبت می‌گردد.

چگونه لاگ‌های حملات را پاکسازی یا دانلود کنیم؟

از تب لاگ حملات و رادار، با کلیک بر روی دکمه «دانلود گزارش CSV» می‌توانید گزارش کامل را برای تحلیل امنیتی در اکسل دریافت کنید و با دکمه «پاکسازی همه لاگ‌ها» جدول دیتابیس را خالی نمایید. همچنین با کلیک بر روی دکمه «مسدودسازی IP» در هر سطر، مهاجم مستقیماً به لیست سیاه افزوده می‌شود.

در صورت تمایل به بازگشت به نقطه شروع، با کلیک روی دکمه زیر تمامی تنظیمات، تم‌ها، لیست‌های مسدودی و قوانین فایروال به حالت اولیه بازنشانی می‌شوند. در این حالت، چالش کپچا و استایل شیشه‌ای صفحه ورود (WP-Login Styler) غیرفعال خواهند شد.

بازگردانی تمام تنظیمات به حالت خام و غیرفعال اولیه کپچا، استایل ورود و تمامی ماژول‌ها خاموش می‌شوند و فرم‌ها به حالت پیش‌فرض وردپرس بازمی‌گردند.
